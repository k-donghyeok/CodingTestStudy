순차적 데이터란 무엇일까?
	특징
	1. 순서가 중요하다
		데이터의 순서가 바뀌면 의미가 달라진다
	2.장기 의존성
		멀리 떨어진 과거의 정보가 현재/미래의 영향을 준다
	3.가변 길이
		순차 데이터는 길이가 일정하지 않고,단어 수도 제각각이다.
RNN
	전통적인 인공신경망(MLP,CNN)들은 고정된 길이의 입력을 받아 가변 길이의 데이터를 	처리하기에 적합하지 않다

	RNN 은 가변길이의 입력을 받을수 있고 이전 입력을기억할수 있기 때문에
	순차적 데이터 처리에 적합함

	RNN 도 역전파 과정에서 기울기 소실 문제가 발생함

LSTMs 
	기울기 소실 문제를 해결 하기위해 제안된 RNN의 한 종류
	RNN 은 시점 t에서 길이가 n인 벡터 hidden state 와 cell state 를 가진다
	Hidden state 에는 short-term information
	Cell state 에는 long-term information 을 저장한다
	LSTMs는 cell state 에서 정보를 읽고 지우고 기록 할수있다
	forget gate - 이전 cell state 에서 무엇을버리고 무엇을 유지할지 결정
	
	input gate - 새 정보 중 얼마나 cell state 에 쓸지 결정
	output gate - cell state 중 얼마나 hidden state 로 내보낼지 결정
	

언어모델
	n-gram 언어모델
	n-gram 이란 연속된 n 개의 단어 묶음을 말한다
	
seq2seq - 2개의 RNN 또는 2개의 LSTMs 로 구성되어있는 인코더 디코더 모델
 
	인코더 - 영어문장을 벡터로 변환
			
	디코더 - 변환된 벡터를 가지고 프랑스어를 생성하는 역할
		theacher Forcing
		모델이 스스로 예측한 단어 대신 정답 단어를 디코더 입력을 강제로 넣어줌으로		써 빠르고 안정적이게 학습을 수행하는 방법
